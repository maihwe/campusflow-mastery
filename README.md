# CampusFlow Mastery

Personal rebuild of CampusFlow from scratch — one PR at a time.

## Goal

Build the full CampusFlow Next application independently, with reviews from a senior collaborator. Learning outcome: be able to build the app solo without AI assistance by the end.

## Structure

- campusflow/ — application code
- tests/ — unittest test files
- docs/ — baseline, design decisions, AI learning log

## How to run

    python3 main.py

Requires Python 3.10+. No external dependencies — standard library only.

## How to test

    python3 -m unittest discover -s tests -v
